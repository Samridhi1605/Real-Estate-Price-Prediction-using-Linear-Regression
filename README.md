# Real Estate Price Prediction using Linear Regression

This project aims to predict real estate prices in Bengaluru using a Linear Regression model. By analyzing various features of properties, the model provides estimated prices to assist buyers and sellers in making informed decisions.

## 📁 Project Structure

- `banglore_home_prices_final.ipynb`: Jupyter Notebook containing the data analysis and model training process.
- `banglore_home_prices_model.pickle`: Serialized Linear Regression model for deployment.
- `columns.json`: JSON file listing the features used in the model.
- `Bengaluru_House_Data.csv`: Original dataset containing property details.
- `bhp.csv`: Cleaned dataset used for model training.

## 🧠 Key Features

- Data preprocessing including handling missing values and outliers.
- Feature engineering to convert categorical variables into numerical formats.
- Training a Linear Regression model to predict property prices.
- Evaluation of model performance using appropriate metrics.
- Saving the trained model for future predictions.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## 📊 Dataset

The dataset contains information about various properties in Bengaluru, including features like location, size, total square footage, number of bathrooms, and balconies.
